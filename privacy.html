1. 수집·처리 개요

Calqio는 회원가입·문의 폼을 통한 계산기 입력값의 서버 저장을 하지 않습니다. 계산은 사용자 브라우저에서 JavaScript로 수행됩니다. 다만 아래와 같은 데이터 처리가 발생할 수 있습니다.

  • Google AdSense — 페이지에 포함된 광고 스크립트(ca-pub-8205853473793766)가 Google과 연동될 수 있으며, 광고 제공·측정·사기 방지 목적으로 쿠키·기기 식별자 등이 처리될 수 있습니다. 자세한 내용은 Google 개인정보처리방침 및 AdSense 프로그램 정책을 참고하세요.
  • 호스팅(Vercel) — 웹 페이지·정적 파일 전달 과정에서 IP 주소, User-Agent, 요청 URL 등 표준 서버 로그가 호스팅 사업자 측에서 처리될 수 있습니다. Calqio가 이 로그를 직접 열람·연동하는지는 운영 설정에 따르며, 본 정책 작성 시점에 별도 분석 대시보드 연동은 확인되지 않았습니다.
  • 브라우저 저장 — 다크/라이트 테마 선택은 localStorage 키 calqio_theme에 저장됩니다(사이트 재방문 시 UI 설정 복원).
  • URL 공유 — 일부 계산기(예: 복리, FIRE)는 입력값을 주소창 쿼리 문자열에 반영합니다. 링크를 공유하면 해당 URL을 여는 사람·링크가 포함된 페이지·분석·광고 도구가 URL을 볼 수 있습니다. Calqio 서버에 계산값을 저장하지 않더라도 URL 자체가 입력값을 노출할 수 있습니다.
  • 환율 참고 API — 양도세 계산기 등에서 브라우저가 api.exchangerate-api.com에 USD 기준 환율을 요청합니다. 이때 사용자 IP 등이 해당 API 운영자에게 전달될 수 있습니다. 표시 환율은 실시간 시장 호가가 아닌 제3자 제공 일일/캐시 데이터일 수 있으며, 화면에 표시된 조회 시각을 확인하세요.

Google Analytics(gtag) 코드는 2026년 3월 저장소 기준 HTML에 포함되어 있지 않았습니다. Search Console 등록만으로 방문 분석 코드가 설치된 것은 아닙니다. 향후 Analytics를 추가하면 이 방침을 업데이트합니다.

2. 쿠키·동의(EEA·영국·스위스 등)

개인 맞춤 광고·일부 광고 쿠키는 해당 지역에서 Google 인증 CMP·TCF 등 적법한 동의 절차가 필요할 수 있습니다(AdSense 지역별 동의, Google EU 사용자 동의 정책). Calqio는 현재 자체 제작 배너를 Google CMP의 대체 수단으로 사용하지 않습니다. EEA 등 유입 비중은 운영자가 Analytics 없이는 UNKNOWN일 수 있으며, 광고 활성화·지역 트래픽 확인 후 CMP 도입 여부를 검토해야 합니다.
